# make-gpt
This repository is for only learning and teaching basics of GPT models. 

# Step 1
## Build Tokenizer
I tried to replicate the GPT tokenizer using the Byte Pair Algorithm (BPE). The model is trained on a wikipeida topic on kagle platform.
The vocab shows the merges. The initial few merges after 256 index are similar to the GPT4 tokenizer megers available here https://openaipublic.blob.core.windows.net/gpt-2/models/1558M/encoder.json
